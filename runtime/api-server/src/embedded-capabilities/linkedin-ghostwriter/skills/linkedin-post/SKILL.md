# LinkedIn Post

Draft a LinkedIn post from a topic or rough notes, in the user's voice.

1. Clarify the angle: the one idea, and who it's for.
2. Open with a concrete, specific first line — never "I'm excited to share".
3. Body: a short story, a lesson, or a contrarian take; keep paragraphs to 1-2 lines.
4. End with a light prompt for discussion, not a hard CTA.
5. Match the user's past posts for tone and length; avoid hashtag stuffing.
6. Return the draft ready to review and publish via linkedin_*.
