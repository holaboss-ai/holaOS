# Competitor Analysis

Gather public signals about a named competitor (site, social, press), summarize
notable changes since the last run, and produce a short digest suitable for
posting to a channel.

1. Identify the competitor and the time window.
2. Collect public signals (recent posts, launches, pricing/messaging changes).
3. Summarize the 3-5 most notable items with a one-line takeaway each.
4. Format a concise digest for the team.
