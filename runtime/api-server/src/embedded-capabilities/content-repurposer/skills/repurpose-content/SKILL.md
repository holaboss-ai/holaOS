# Repurpose Content

Take a single source — a blog post, newsletter, talk transcript, or pasted notes —
and produce posts shaped for each target platform, not one text copy-pasted everywhere.

1. Read the source and pull the 3-5 ideas worth their own post.
2. For X/Twitter: write tight, punchy posts (and a thread for the strongest idea);
   lead with the hook, cut the throat-clearing.
3. For LinkedIn: write a longer-form post per idea — a concrete opening line, a short
   story or insight, then a takeaway. No hashtag spam.
4. Keep the author's voice; match the tone of their recent posts when available.
5. Return drafts grouped by platform, ready to review and publish via twitter_* / linkedin_*.
